# The puzzle this project started from: a 6x6 killer sudoku in a newspaper, transcribed from a
# photograph. Only the printed totals and where they sit are given here — the cage shapes are not,
# because they were not known. `killer.wac` derives them:
#
#     wac run src/killer.wac < examples/photographed.txt
#
# It works because eleven totals adding to 126 = 6 x 21 can only be a partition of all 36 cells,
# and because a cage's total is printed in its topmost-then-leftmost cell.
